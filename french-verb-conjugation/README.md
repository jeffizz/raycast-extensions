## Practice

过去分词和现在分词单独一行。变位格下面不再标 je / tu。回车在同一时态向下。`⌘↩` 检查。错的时候，正确拼写会高亮。

格子的圆角是 Raycast 自带的，去不掉；内边距已经收到最小。

## Practice My Verbs

使用「我的动词」列表，一次练习一个时态或分词：动词做列每页最多 6 个，人称做列每页最多 5 个。列表为空时可从提示页进入编辑。

* `⌘0`：分词；`⌘1`–`⌘6`：六个时态。
* `⌘⇧S`：朗读当前选中格所属动词的当前时态或分词。
* `⌘⇧[` / `⌘⇧]`：上一页 / 下一页；动作仅在有对应页面时显示。
* `⌘↩`：检查当前页已填写的格子；每次检查为有填写的动词各增加一次练习次数。
* `⌘⇧H`：显示 / 隐藏当前页全部答案，不会覆盖输入。
* `⌘⇧⌫`：清空当前页当前时态的输入。
* 在 Actions 中切换布局；默认动词做列、人称做行，或切换为人称做列。布局选择会保存，切换时会跳到当前选中动词所在的页面。

切换页或时态会保留本次会话中已经填写的内容；关闭命令后输入不会保存。

## 变位形式显示

变位表默认只显示词库中的第一种形式；在扩展设置中勾选「显示其他变位形式」可默认显示全部形式。单形式模式下，带 `*` 的时态表示其中有其他形式。表格页面按 `⌥⌘V` 可临时切换，只影响当前页面，不会修改默认设置。搜索的是另一种变位时，单形式模式会优先显示并加粗该查询词。练习检查仍接受词库中的所有正确形式。

## 最近查询和练习

* **Conjugate** 的「最近查询」按最近打开变位表的顺序排列；每次打开记一次查询。
* **Practice** 的「最近练习」按最近检查答案的顺序排列。至少填写一格并检查才记一次；Practice My Verbs 检查时，每个有填写的动词各记一次。已有练习次数保留，最近顺序从更新后开始记录。
* 找不到搜索词时显示初始动词列表；从变位表按返回可回到列表。

## 我的动词

`⌘K` → 编辑我的动词，一行一个原形。也可以把当前动词加入或移出。常用和全部都还在。没输入时，「我的」排在常用前面。随机我的只抽这份列表。

已经导入过的话，再 Import 一次这个文件夹。

## LeXiK 词形库

**Conjugate** 支持在选择列表输入变位词形（如 `peut`、`fini`），也支持选中文本后启动。选择匹配的动词原形并打开后，六个时态内的匹配格加粗；分词和其他未显示的时态可反查原形，但不会高亮。

离线反查使用 `assets/lexik-verbs.sqlite`。数据库由 LeXiK 派生，只保留 `VERB` 和 `AUX` 分析；数据来源、CC BY-SA 4.0 许可与重建方法见 `assets/LEXiK-NOTICE.md`。重建命令：`python3 scripts/build-lexik-db.py`。
